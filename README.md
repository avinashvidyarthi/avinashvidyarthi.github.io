# Avinash Kumar - Portfolio

A minimalist, modern portfolio website showcasing my work as a Cloud Engineer and DevOps Specialist.

## 🚀 Features

- **Minimalist Design**: Clean, modern interface focused on content
- **Fully Responsive**: Works seamlessly on all devices
- **Pure HTML/CSS/JS**: No frameworks, fast loading times
- **Smooth Animations**: Subtle scroll animations and transitions
- **Mobile-First**: Optimized for mobile devices
- **Lightweight**: Under 100KB (excluding images)

## 📁 Structure

```
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styles
├── js/
│   └── script.js       # Interactive functionality
├── img/                # Images and icons
├── avinashResume.pdf   # Resume PDF
└── README.md           # This file
```

## 🛠️ Technologies

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6+)
- Intersection Observer API
- CSS Animations

## 📱 Sections

1. **Hero** - Introduction and quick links
2. **About** - Professional summary and contact info
3. **Experience** - Work history timeline
4. **Skills** - Technical skills and certifications
5. **Projects** - Featured projects and blog posts
6. **Contact** - Contact form and social links

## 🎨 Design Philosophy

- **Minimalist**: Focus on content, not clutter
- **Modern**: Contemporary design patterns
- **Accessible**: Semantic HTML and ARIA labels
- **Fast**: Optimized for performance
- **Clean**: Easy to read and navigate

## 🚀 Getting Started

Simply open `index.html` in your browser. No build process required!

For local development:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

Then visit `http://localhost:8000`

## 📝 Customization

All colors and design tokens are defined as CSS custom properties in `:root`:

```css
:root {
    --primary-color: #2563eb;
    --text-primary: #1f2937;
    --bg-primary: #ffffff;
    /* ... */
}
```
